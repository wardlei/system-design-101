虽然上云的起步成本可能很低甚至免费，但其复杂性往往带来隐性成本，最终导致高额的云账单。

本文的目的并不是劝退大家使用云。我本人是云的忠实粉丝。我只是想提高大家对这一问题的认识，因为这是一个不常被讨论的关键话题。

![](https://assets.bytebytego.com/diagrams/0148-cloud-hidden-costs.png)

虽然这里以 AWS 为例，但类似的成本结构同样适用于其他云服务商。

## 云计算的隐性成本

*   **免费套餐的模糊性：** AWS 为常见服务提供三种不同类型的免费方案。然而，不在免费套餐内的服务是会收费的。即使是提供免费资源的服务，通常也有额度限制。超出该限制可能会产生超出预期的费用。

*   **弹性 IP 地址（Elastic IP）：** AWS 允许最多五个弹性 IP 地址。超出这一限制会产生少量按小时计费的费率，具体因区域而异。这是一项持续性收费。

*   **负载均衡器（Load Balancer）：** 即使没有实际使用，也会按小时计费。此外，如果数据在负载均衡器中流入流出，你还会面临额外的费用。

*   **弹性块存储（EBS）费用：** EBS 按 GB/月计费。无论 EBS 卷是否被挂载、是否被实际使用，都会被收费。

*   **EBS 快照：** 删除 EBS 卷并不会自动删除关联的快照。孤立的 EBS 快照仍会出现在你的账单上。

*   **S3 访问费用：** 虽然 S3 存储的定价通常比较合理，但与访问存储对象相关的费用（例如 GET 和 LIST 请求）有时会超过存储本身的费用。

*   **S3 不完整分片上传：** 如果 S3 中的分片上传（multipart upload）未能成功完成，你仍需要为已成功上传的部分付费。务必清理这些残留，以避免不必要的费用。

*   **数据传输费用：** 将数据传输进 AWS（例如从数据中心上传）是免费的。然而，将数据传出 AWS 可能要贵得多。
