如果我们写的代码能自动变成架构图，那该多好？

我最近发现了一个 GitHub 仓库，正好能做到这一点：Diagram as Code，用于云系统架构的原型设计。

## 它能做什么？

*   用 Python 代码绘制云系统架构图。

*   图表还可以直接在 Jupyter Notebooks 中渲染。

*   不需要任何设计工具。

*   支持以下云厂商：AWS、Azure、GCP、Kubernetes、阿里云、Oracle Cloud 等。
