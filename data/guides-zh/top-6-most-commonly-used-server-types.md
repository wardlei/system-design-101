![服务器类型](https://assets.bytebytego.com/diagrams/0327-server-types.png)

## 1. Web 服务器

托管网站，并通过互联网向客户端提供 Web 内容。

## 2. 邮件服务器

负责在网络中发送、接收和路由电子邮件。

## 3. DNS 服务器

将域名（如 bytebytego.com）转换为 IP 地址，使用户能够通过易于阅读的名称访问网站。

## 4. 代理服务器

一种中间服务器，充当客户端与其他服务器之间的网关，提供额外的安全性、性能优化和匿名性。

## 5. FTP 服务器

促进客户端与服务器之间通过网络传输文件。

## 6. 源站服务器（Origin Server）

托管内容的中心来源，内容会被缓存并分发到边缘服务器，以便更快地交付给最终用户。
