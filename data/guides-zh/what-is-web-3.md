上图从鸟瞰视角展示了 Web 1.0 / Web 2.0 / Web 3.0。

![](https://assets.bytebytego.com/diagrams/0416-what-is-web-3.png)

*   Web 1.0 —— 只读

1991 年到 2004 年间，互联网就像一个**静态页面的目录**。我们可以通过从一个超链接跳转到另一个超链接来浏览内容。它不提供与内容的任何交互。

*   Web 2.0 —— 读写

从 2004 年至今，互联网已经发展出搜索引擎、社交媒体应用，以及由推荐算法驱动的应用。

由于这些应用将人类行为数字化，并在用户与这些应用交互时持久化用户数据，大公司便利用用户数据投放广告，这成为 Web 2.0 中**主要的商业模式之一**。

这就是为什么人们说，这些应用比你的朋友、家人甚至你自己更了解你。

*   Web 3.0 —— 读、写、拥有

由于区块链和去中心化应用的发展，这一理念近来被广泛讨论。创作者的内容存储在 IPFS（星际文件系统，InterPlanetary File System）上，并且**归用户所有**。

如果应用想要访问这些数据，它们需要获得用户的**授权**，并为此**付费**。

在 Web 3.0 中，所有权的变化可能会带来一些重大的创新。
