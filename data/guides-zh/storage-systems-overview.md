# **存储系统概述**

让我们从整体上回顾一下各类存储系统。

存储系统大致可分为三大类：

*   块存储
*   文件存储
*   对象存储

上图展示了不同存储系统之间的对比。

## 块存储

块存储最早出现于 20 世纪 60 年代。常见的存储设备，如物理连接到服务器的硬盘驱动器（HDD）和固态硬盘（SSD），都属于块存储。

块存储以卷（volume）的形式向服务器呈现原始数据块。这是最灵活、最通用的存储形式。服务器可以对原始数据块进行格式化并将其用作文件系统，也可以将这些数据块的控制权交给应用程序。数据库或虚拟机引擎等应用程序会直接管理这些数据块，以充分榨取其中的每一分性能。

块存储并不局限于物理连接的存储。块存储可以通过高速网络或行业标准的连接协议（如光纤通道 FC 和 iSCSI）连接到服务器。从概念上讲，网络连接的块存储仍然呈现原始数据块。对服务器而言，它与物理连接的块存储工作方式相同。无论是网络连接还是物理连接，块存储都完全归属于单个服务器，并不是共享资源。

## 文件存储

文件存储构建于块存储之上。它提供了更高层次的抽象，使文件和目录的处理更加容易。数据以文件的形式存储在分层目录结构下。文件存储是最常见的通用存储解决方案。文件存储可以通过 SMB/CIFS 和 NFS 等常见的文件级网络协议供大量服务器访问。访问文件存储的服务器无需处理管理数据块、格式化卷等复杂问题。文件存储的简单性使其成为在组织内部共享大量文件和文件夹的绝佳解决方案。

## 对象存储

对象存储是一种较新的存储方式。它做了一个非常明确的取舍：牺牲性能以换取高持久性、超大规模和低成本。它面向相对“冷”的数据，主要用于归档和备份。对象存储将所有数据以对象的形式存储在扁平结构中，没有分层的目录结构。数据访问通常通过 RESTful API 提供。与其他存储类型相比，它的速度相对较慢。大多数公有云服务提供商都提供对象存储服务，例如 AWS S3、Google 块存储和 Azure Blob 存储。
