API 是互联网通信的骨干。每个开发者都需要学习 API。这里有一份涵盖最重要主题的路线图：

*   **API 简介**
    *   API 是一套用于构建应用的协议和工具。存在不同类型的 API，例如公有 API、私有 API 和合作伙伴 API。
*   **API 术语**
    *   需要理解各种 API 术语，例如 HTTP 版本、cookie 和缓存。
*   **API 风格**
    *   最常见的 API 风格有 REST、SOAP、GraphQL、gRPC 和 WebSockets。
*   **API 身份认证**
    *   Basic Auth、Token、JWT、OAuth 和 Session Auth 等 API 身份认证技术。
*   **API 文档**
    *   好的 API 是易于理解的。Swagger、Postman、Redoc 和 DapperDox 等 API 文档工具使之成为可能。
*   **API 特性**
    *   关键的 API 特性包括分页、参数、幂等性、API 版本管理、HATEOAS 和内容协商。
*   **API 性能技术**
    *   常见的 API 性能技术有缓存、限流、负载均衡、分页、数据库索引、扩容和性能测试。
*   **API 网关**
    *   了解 Amazon API Gateway、Azure API Services、Kong、Nginx 等 API 网关。
*   **API 实现框架**
    *   最流行的 API 开发框架有 Node.js、Spring、Flask、Django 和 FastAPI。
*   **API 集成模式**
    *   了解网关、事件驱动、webhook、轮询和批处理等各种 API 集成模式。
