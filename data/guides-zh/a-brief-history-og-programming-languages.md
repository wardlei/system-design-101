C、C++、Java、Javascript、Typescript、Golang、Rust，编程语言在过去 70 年里是如何演进的？

<img src="https://assets.bytebytego.com/diagrams/0305-programming-languages.png" alt="编程语言历史">

*   打孔卡片是第一代编程语言。面向机器的汇编语言是第二代编程语言。面向人类的第三代语言自 1957 年起就已经出现。

*   Fortran 和 LISP 等早期语言提出了垃圾回收、递归、异常等概念。这些特性至今仍然存在于现代编程语言中。

*   1972 年，两门影响深远的语言诞生了：Smalltalk 和 C。Smalltalk 极大地影响了脚本语言和客户端语言。C 语言则是为 Unix 编程而开发的。

*   在 1980 年代，面向对象语言因在图形用户界面方面的优势而流行起来。Object-C 和 C++ 是其中两个著名的代表。

*   在 1990 年代，个人电脑变得更便宜。这个阶段的编程语言强调安全性和简洁性。Python 诞生于这个十年，它易于学习和扩展，迅速流行开来。1995 年，Java、Javascript、PHP 和 Ruby 相继诞生。

*   2000 年，微软发布了 C#。尽管它与 .NET 框架捆绑在一起，但这门语言携带了大量先进的特性。

*   在 2010 年代，许多语言被开发出来，用于改进 C++ 或 Java。在 C++ 家族中，有 D、Rust、Zig，以及最近的 Carbon。在 Java 家族中，有 Golang 和 Kotlin。Flutter 的使用让 Dart 流行起来，Typescript 则为了与 Javascript 完全兼容而开发。此外，苹果最终发布了 Swift 来取代 Object-C。
