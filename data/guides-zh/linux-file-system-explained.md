Linux 文件系统曾经像一座杂乱无章的小镇，人们随心所欲地建造自己的房子。然而，1994 年，文件系统层次结构标准（Filesystem Hierarchy Standard，FHS）被引入，为 Linux 文件系统带来了秩序。

通过实施 FHS 这样的标准，软件可以确保在各种 Linux 发行版中保持一致的结构。尽管如此，并非所有 Linux 发行版都严格遵守这一标准。它们往往会融入自己独特的元素，或满足特定的需求。

要精通这一标准，你可以从探索开始。使用 "cd" 等命令进行导航，用 "ls" 列出目录内容。把文件系统想象成一棵树，从根目录（/）开始。久而久之，你会对它了如指掌，成为一名熟练的 Linux 管理员。
