## TCP/IP

TCP/IP 协议由 IETF 组织开发，是互联网的基础，也是最著名的网络标准之一。

## HTTP

IETF 还开发了 HTTP 协议，它对所有 Web 开发者来说都至关重要。

## SQL

结构化查询语言（SQL）是一种用于管理数据的领域特定语言。

## OAuth

OAuth（Open Authorization）是一种用于访问委托的开放标准，通常用于在不暴露用户密码的情况下，授予网站或应用程序对用户信息的有限访问权限。

## HTML/CSS

借助 HTML，网页可以在不同浏览器中一致地呈现，从而减少了花在兼容性问题上的开发工作。HTML 标签。

CSS 标准通常与 HTML 结合使用。

## ECMAScript

ECMAScript 是一种标准化的脚本语言规范，是多种编程语言的基础，其中最著名的是 JavaScript。

## ISO 日期

开发者每天都会遇到时间格式不一致的问题，这很常见。ISO 8601 是由 ISO（国际标准化组织）开发的日期和时间格式标准，旨在为跨国界、跨文化和跨行业的日期与时间数据交换提供一种通用格式。

## OpenAPI

OpenAPI，也称为 OpenAPI 规范（OAS），是一种用于描述和记录 RESTful API 的标准化格式。
