HTTP 是 Web 的语言，天生就是“无状态”的。但是，我们都想要那种无缝、连续的浏览体验，对吧？于是默默无闻的英雄登场了——Cookie！

那么，这份 Cookie 小传单里说了些什么呢：

*   HTTP 就像一条没有记忆的金鱼——它会瞬间忘记你！但 Cookie 会赶来救援，为你的 Web 交互加上这层“会话秘制酱料”。

*   Cookie？可以把它们想象成你递给 Web 服务器的小纸条，上面写着：“请记住我！”没错，它们就存储在那里，就像被珍藏的纪念品。

*   浏览器就像是 Cookie 的门卫，确保你的 Cookie 不会在错误的网站上“乱串门”。

*   最后，认识一下 Cookie 里的明星们——SameSite、Name、Value、Secure、Domain 和 HttpOnly。它们就是在饼干罐（cookie jar）里定规矩的酷小孩！
