面向对象编程（OOP）从 20 世纪 60 年代就已出现，但真正流行起来是在 20 世纪 90 年代，随着 Java 和 C++ 等语言的兴起。

为什么 OOP 很重要？OOP 让你能够为数字对象创建蓝图（称为类），这些对象知道如何彼此通信，从而在软件中实现令人惊叹的功能。拥有一个井井有条的工具箱，而不是一个杂乱堆满工具的抽屉，能让你的代码更整洁、更易于修改。

要掌握 OOP，可以把它想象成创造能以无数种方式组合的数字乐高积木。找一本书或看一些教程，然后练习写代码——没有比实践更好的学习方式了！

不要害怕 OOP——它是程序员工具箱中的强大工具。通过一些练习，你将能够开发出从精巧的小应用到数字化摩天大楼的各种软件！
