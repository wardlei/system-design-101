![](https://assets.bytebytego.com/diagrams/0017-9-types-of-api-testing.png)

*   **冒烟测试（Smoke Testing）**
    在 API 开发完成后进行。简单地验证 API 是否正常工作、有没有出问题。
*   **功能测试（Functional Testing）**
    根据功能需求创建测试计划，并将实际结果与预期结果进行对比。
*   **集成测试（Integration Testing）**
    这种测试将多个 API 调用组合起来，执行端到端测试。测试服务内部通信和数据传输。
*   **回归测试（Regression Testing）**
    这种测试确保 bug 修复或新功能不会破坏 API 的现有行为。
*   **负载测试（Load Testing）**
    通过模拟不同负载来测试应用的性能，然后我们可以计算出应用的容量。
*   **压力测试（Stress Testing）**
    我们故意给 API 制造高负载，测试 API 是否还能正常工作。
*   **安全测试（Security Testing）**
    测试 API 抵御所有可能的外部威胁的能力。
*   **UI 测试（UI Testing）**
    测试 UI 与 API 的交互，确保数据能够被正确展示。
*   **模糊测试（Fuzz Testing）**
    向 API 注入无效或意外的输入数据，试图让 API 崩溃，从而发现 API 的漏洞。
