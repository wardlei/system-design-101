![](https://assets.bytebytego.com/diagrams/0030-18-common-ports-you-must-know.png)

*   **FTP（文件传输协议）：** 使用 TCP 端口 21
*   **SSH（安全登录 Shell）：** 使用 TCP 端口 22
*   **Telnet：** 使用 TCP 端口 23 进行远程登录
*   **SMTP（简单邮件传输协议）：** 使用 TCP 端口 25
*   **DNS：** 使用 UDP 或 TCP 端口 53 进行 DNS 查询
*   **DHCP 服务器：** 使用 UDP 端口 67
*   **DHCP 客户端：** 使用 UDP 端口 68
*   **HTTP（超文本传输协议）：** 使用 TCP 端口 80
*   **POP3（邮局协议第 3 版）：** 使用 TCP 端口 110
*   **NTP（网络时间协议）：** 使用 UDP 端口 123
*   **NetBIOS：** 使用 TCP 端口 139 提供 NetBIOS 服务
*   **IMAP（互联网消息访问协议）：** 使用 TCP 端口 143
*   **HTTPS（安全 HTTP）：** 使用 TCP 端口 443
*   **SMB（服务器消息块）：** 使用 TCP 端口 445
*   **Oracle DB：** 使用 TCP 端口 1521 作为 Oracle 数据库通信端口
*   **MySQL：** 使用 TCP 端口 3306 作为 MySQL 数据库通信端口
*   **RDP：** 使用 TCP 端口 3389 提供远程桌面协议服务
*   **PostgreSQL：** 使用 TCP 端口 5432 进行 PostgreSQL 数据库通信
