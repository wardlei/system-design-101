什么是对象存储？

对象存储使用对象来存储数据。与使用层次结构存储文件的文件存储、或将文件切成等大小块的块存储不同，对象存储将元数据与对象存储在一起。典型的产品包括 AWS S3、Google Cloud Storage 和 Azure Blob Storage。

对象存储在格式上非常灵活，而且易于扩展。

## 场景 1：数据归档

随着业务数据量的不断增长，我们不可能把所有数据都存放在核心存储系统中。我们需要分层存储方案。对象存储可以用来归档旧数据，比如用于审计或客户对账单的历史数据。这是一种经济高效的方式。

## 场景 2：非结构化数据存储

我们经常需要处理非结构化或半结构化数据。过去，它们通常以 blob 形式存放在关系型数据库中，效率很低。对象存储非常适合音乐、视频文件和文本文档。Spotify、Netflix 等公司就使用对象存储来持久化它们的媒体文件。

## 场景 3：云原生存储

对于云原生应用，我们需要数据存储系统具备灵活性和可扩展性。各大公有云厂商的对象存储产品都提供了方便的 API 访问，是经济实惠的存储选择。

## 场景 4：数据湖

分布式系统中存在多种类型的数据。基于对象存储的数据湖为各条业务线提供了一个集中存放数据的好地方，便于后续进行数据分析或机器学习。对象存储高效的读写能力支撑了数据处理管道的后续环节，包括 ETL（抽取-转换-加载）或构建数据仓库。

## 场景 5：物联网（IoT）

IoT 传感器会产生各种各样的数据。对象存储可以存储这类时间序列数据，之后再运行分析或 AI 算法。各大公有云厂商都提供了将原始 IoT 数据导入对象存储的管道。

## 场景 6：备份与恢复

对象存储可以用来存储数据库或文件系统的备份。之后可以加载这些备份进行快速恢复，从而提升系统的可用性。
