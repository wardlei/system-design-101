## 1. 协作工具

软件开发是一项社交活动。学会使用 Jira、Confluence、Slack、MS Teams、Zoom 等协作工具。

## 2. 编程语言

挑选并精通一到两门编程语言。可以从 Java、Python、JavaScript、C#、Go 等语言中选择。

## 3. API 开发

深入学习 REST、GraphQL 和 gRPC 等 API 开发方式的方方面面。

## 4. Web 服务器与托管

了解 Web 服务器，以及 AWS、Azure、GCP 和 Kubernetes 等云平台。

## 5. 认证与测试

学习如何使用 JWT、OAuth2 等认证技术来保护你的应用。同时，掌握 TDD、端到端测试和性能测试等测试技术。

## 6. 数据库

学会使用关系型数据库（Postgres、MySQL 和 SQLite）和非关系型数据库（MongoDB、Cassandra 和 Redis）。

## 7. CI/CD

选择 GitHub Actions、Jenkins 或 CircleCI 等工具，学习持续集成和持续交付。

## 8. 数据结构与算法

掌握数据结构与算法（DSA）的基础知识，包括大 O 表示法、排序、树和图等主题。

## 9. 系统设计

学习系统设计概念，如网络、缓存、CDN、微服务、消息传递、负载均衡、复制、分布式系统等。

## 10. 设计模式

掌握设计模式的应用，如依赖注入、工厂、代理、观察者、门面等模式。

## 11. AI 工具

为了让自己的职业生涯经得起未来的考验，学会利用 GitHub Copilot、ChatGPT、Langchain 等 AI 工具和提示词工程（Prompt Engineering）。
