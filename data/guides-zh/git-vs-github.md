Git 和 GitHub 是流行的版本控制工具。它们协同工作、互为补充，共同提供高效的源代码管理。

从高层次看，Git 专注于版本控制和代码共享，而 GitHub 专注于集中式的源代码托管，以便与其他开发者共享。

不过，它们之间存在一些关键区别。

## 关键区别

*   Git 是一个免费的开源版本控制工具。GitHub 是一个基于云的付费服务，在云端运行 Git。

*   Git 安装在开发者的本地机器上。GitHub 托管在云端。

*   Git 由 Linux 基金会维护。GitHub 归微软所有。

*   Git 可以管理 Git 仓库中文件的不同编辑版本。GitHub 是上传 Git 仓库副本的空间。

*   Git 支持版本控制和源代码管理。GitHub 可用于代码托管、协作和项目管理。

*   Git 的外部工具配置很少。GitHub 提供了一个活跃的工具集成市场。

最后，你可以在没有 GitHub 的情况下使用 Git，但不能在没有 Git 的情况下使用 GitHub。
