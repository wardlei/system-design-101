![API 网关的三大使用场景](https://assets.bytebytego.com/diagrams/0073-top-3-api-gateway-use-cases.png)

API 网关位于客户端与服务之间，为它们提供 API 通信。

*   **API 网关有助于构建生态系统。**
    用户可以利用 API 网关访问更丰富的工具。生态系统中的合作伙伴彼此协作，为用户提供更好的集成。
*   **API 网关构建 API 市场**
    API 市场为所有人承载基础功能。开发者和企业可以在这个生态系统中轻松开发或创新，并在市场上销售 API。
*   **API 网关提供多平台兼容性**
    当面对多个平台时，API 网关可以帮助跨越多个复杂架构进行工作。
